## 2. تحليل الترابط (Binding Analysis)

### 2.1 العناصر المربوطة بشكل كامل ✅
جميع عناصر التحكم الأساسية مربوطة بشكل صحيح:
- حقول القالب → `state.templateValues` ← `renderSlides()` ← `renderPreviewFrame()`
- أزرار القوالب → `state.selectedTemplateId` ← `applyTemplateSelection()` ← `renderSlides()`
- أشرطة التمرير (Scale, X, Y, Font Size) → real-time preview
- عناصر التحكم بالخلفية → real-time preview
- ألوان القالب (color picker + hex) → real-time preview
- عناصر التحكم بالصوت (voiceover, music) → real-time preview
- المؤثرات البصرية (piano keys) → `state.effects` → preview
- مشروع (حفظ/فتح) → IPC مع backend
- الرندر → IPC مع backend

### 2.2 عناصر أحادية الاتجاه (Read-only) 📖
- `#slides-count`, `#selected-template-badge`, `#template-description`
- `#runtime-summary`, `#preview-summary`
- `#progress-percent`, `#progress-fill`, `#progress-label`
- `#status-title`, `#status-text`

### 2.3 عناصر غير مربوطة/معطلة ❌
- `#overlay-select` — `display:none`, له Event listener لكنه مخفي
- `#text-preset-select` — `display:none`, موجود كـ fallback
- Hidden preview controls — `display:none`, كود قديم غير مستخدم

## 3. المشاكل الرئيسية (UX Problems)

### 3.1 ازدحام وترتيب خاطئ

#### 🚩 P1 — اختيار القالب مدفون في أسفل التبويب
أهم إجراء في Qawaleb هو **اختيار القالب**. لكنه موجود في **القسم الرابع** من تبويب "قوالب"، بعد:
1. الموضع والحجم (4 أشرطة تمرير)
2. الصورة (كاملة بعناصر تحكم)
3. الخلفية (معاينة + 4 أشرطة تمرير)

يجب على المستخدم التمرير لأسفل للوصول إلى أزرار القوالب. هذا غير بديهي.

#### 🚩 P2 — اسم التبويب "بيانات" غير واضح
التبويب الأول يُسمى "بيانات" لكنه يعرض **حقول القالب الحالي** (مثل: عنوان, نص, مصدر). اسم أدق: "محتوى" أو "إدخال النص" أو "حقول القالب".

#### 🚩 P3 — عناصر تحكم الصورة متكررة
هناك **مكانان** لاختيار الصورة:
1. في تبويب "قوالب" ضمن قسم الصورة (`renderTemplateImageControls`)
2. داخل شبكة حقول القالب في تبويب "بيانات" (إذا كان الحقل من نوع image)

هذا يسبب ارتباكًا: أين يختار المستخدم الصورة؟

#### 🚩 P4 — عناصر تحكم الموضع في التبويب الخطأ
Scale, X, Y (من template) تؤثر على **القالب بأكمله** في المعاينة، لكنها موجودة في تبويب "قوالب" وليست في تبويب "بيانات" أو في شريط جانبي منفصل.

#### 🚩 P5 — الإطارات وشاشة الختام في مكان غريب
`#endpage-select` و `#frame-select` في أسفل تبويب "بيانات". هذه إعدادات **عرض وليست بيانات**. مكانها الأنسب: في قسم منفصل أو في تبويب "القوالب".

### 3.2 عناصر مكررة

#### 🔄 مكرر 1: `#overlay-select` و `#frame-select`
كلاهما يربط `state.frame`. `overlay-select` مخفي. كود قديم.

#### 🔄 مكرر 2: `#text-preset-select` و `#template-color-controls`
`text-preset-select` مخفي. الألوان الآن تُتحكم عبر منتقي ألوان ديناميكي.

### 3.3 غموض وتشتت

#### 🤔 G1 — Piano Effects Bar
شريط "piano keys" (غبار, إضاءة, بريق, إلخ) يستخدم استعارة بيانو بصرية. المستخدم العادي قد لا يفهم أنها أزرار toggle للمؤثرات.

#### 🤔 G2 — قوالب متعددة ذات حقول مختلفة جدًا
عدد الحقول يتراوح بين 3 (Instagram) و13 (Sports). التبويب "بيانات" يتغير بالكامل حسب القالب، مما قد يربك المستخدم.

#### 🤔 G3 — Portrait Controls فقط لقالب واحد
عناصر تحكم الصورة المتقدمة (Portrait) تظهر فقط لـ `points-broadcast`. القوالب الأخرى لا تظهرها، لكن المستخدم قد يتساءل لماذا.

### 3.4 نقص في التغذية الراجعة البصرية

#### 👁️ V1 — لا توجد معاينة مصغرة للقالب قبل الاختيار
أزرار القوالب هي نصوص فقط. لا توجد صور مصغرة أو thumbnails توضح شكل القالب قبل اختياره.

#### 👁️ V2 — `#selected-template-badge` نص فقط
الـ badge يظهر اسم القالب (مثل "خبر عاجل") لكن بدون أي تمييز بصري إضافي.

## 4. 3 خيارات Layout مقترحة

### الخيار A — إعادة هيكلة التبويبات (موصى به)

```
الشريط العلوي (بدون تغيير)
┌─────────────────────────────────────────────────────┐
│  [Logo]  [فتح] [حفظ]  |  ... [قوالب]  [⚙]           │
├──────────────────────┬──────────────────────────────┤
│  التبويبات:          │  المعاينة                    │
│  [محتوى] [تعديل]     │  ┌────────────────────┐      │
│  [صوت] [عرض]         │  │  Remotion Player    │      │
│                      │  └────────────────────┘      │
│  TAB: محتوى          │  [غبار] [إضاءة] [بريق] ...   │
│  ┌──────────────────┐│                              │
│  │ اختيار القالب    ││  ┌──────────────────────────┐│
│  │ [ثمبنايل] [ثمب]   ││  │ حفظ الفيديو            ││
│  │ [ثمب] ...        ││  │ [████████░░] 50%        ││
│  │                  ││  │ [حفظ الفيديو] [⬆] [📁]  ││
│  │ حقول القالب      ││  └──────────────────────────┘│
│  │ [العنوان]        ││                              │
│  │ [النص]           ││                              │
│  │ [المصدر]         ││                              │
│  └──────────────────┘│                              │
├──────────────────────┴──────────────────────────────┤
```

**التغييرات:**
- تبويب "محتوى" (Content) — يجمع بين اختيار القالب + حقوله. القالب يُختار من أعلى التبويب عبر شبكة صور مصغرة.
- تبويب "تعديل" (Edit) — الموضع والحجم + الخلفية + الألوان
- تبويب "صوت" (Audio) — كما هو
- تبويب "عرض" (Display) — الإطارات + شاشة الختام + المدة + المؤثرات

**المزايا:** ترتيب منطقي، القالب + محتواه معًا، إعدادات معدل التجميع في تبويب واحد.
**العيوب:** يزيد عدد التبويبات إلى 4.

**المزايا:** أقل تغيير من الواجهة الحالية، ترتيب أفضل، لا إضافة تبويبات جديدة كثيرة.
**العيوب:** تبقى 3 تبويبات مع إعادة توزيع.

---

## 5. الترشيح النهائي

### ✅ الخيار الموصى به: **الخيار A — إعادة هيكلة التبويبات**

**الأسباب:**
1. **الفصل المنطقي**: كل تبويب له غرض واضح (محتوى / تعديل / صوت / عرض)
2. **اختيار القالب في المكان الصحيح**: أعلى تبويب "المحتوى" مع صور مصغرة
3. **إعدادات التجميع**: كل إعدادات التعديل (موضع، خلفية، ألوان) في تبويب واحد
4. **لا تكرار**: كل عنصر تحكم يظهر مرة واحدة فقط
5. **قابلية التوسع**: يمكن إضافة تبويبات جديدة (مثل "مؤثرات") دون إرباك
